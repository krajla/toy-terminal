# krajla.space

A small terminal in the browser, about me and my cat, Luna.

Type commands, play with Luna, roll some dice, and talk to a chat bot that is a cat. Luna also hides sardines in this machine. Find them all to see how it ends.

Play it at [luna.krajla.space](https://luna.krajla.space).

## Spoilers

All of the source is here, and you can read it. But the hunt is more fun when you play first and read after.

## Run it on your machine

Install [Bun](https://bun.sh). Then:

```sh
bun install
bun run dev      # http://localhost:3000
bun test
bun run build    # writes the static site to dist/
```
